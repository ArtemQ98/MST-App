# Приложение для ТЗ MST
## Архитектура проекта
В проекте не используется архитетура MVVM, так как нет достаточного количества функционала. Я внедрить структуру MVVM, если бы добавил хранение данных в **CoreData** и модель пользователя (User).

## Хранение данных
Данные хранятся в **AppStorage**, а именно хранится статус подписки и имя пользователя. Для более функционального приложения можно было бы использовать **UserDefault** для настроек, или же **CoreData** для хранения и обработки моделей.

## Структура проекта
+ **Models**
+ + SubscriptModel (Модель подписки)
+ **Views**
+ + OnboardingView (Первоначальный экран)
+ + PaywallView (Экран оплаты подписки)
+ + MainView (Главный экран профиля)
+ **Assets**
+ MST_APPApp (Функция **main**)
